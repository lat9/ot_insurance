# Optional/Required Shipping Insurance, v4.1.0

This Zen Cart order-total module enables a site to include an optional  (or required) shipping-insurance fee for a customer's order.

Requires Zen Cart 2.1.0 (or later), PHP 8.0 or later, EO v5.0.3 or later.

Zen Cart support-thread link: https://www.zen-cart.com/showthread.php?50167-Optional-Shipping-Insurance-Module-Support-Thread

Zen Cart download link: https://www.zen-cart.com/downloads.php?do=file&id=232
